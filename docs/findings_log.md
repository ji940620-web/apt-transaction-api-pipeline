### 비교 쿼리

```sql
SELECT
  CASE WHEN EXTRACT(DAY FROM l.deal_date) <= 10 THEN '1-10일'
       WHEN EXTRACT(DAY FROM l.deal_date) <= 20 THEN '11-20일'
       ELSE '21일-말일' END AS period,
  SUM(COALESCE(s.n, 0)) AS before_n,
  SUM(l.n) AS after_n,
  ROUND(SAFE_DIVIDE(SUM(l.n), SUM(COALESCE(s.n, 0))) - 1, 3) AS change
FROM (
  SELECT deal_date, STARTS_WITH(region_name, '서울') AS is_seoul, COUNT(*) AS n
  FROM apt_dataset.v_sales_clean
  WHERE NOT is_bulk AND deal_month = DATE '2026-10-01'
  GROUP BY deal_date, is_seoul
) l
LEFT JOIN apt_dataset.snap_daily_20261110 s
  ON l.deal_date = s.deal_date AND l.is_seoul = s.is_seoul
WHERE l.is_seoul
GROUP BY period
ORDER BY period;
```

21일-말일의 change가 크게 플러스면 신고 지연, 0에 가까우면 실제 감소.
